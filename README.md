
# HATIM 5G

تطبيق أندرويد لإدارة راوتر Huawei H155-383 وقراءة معلومات الاتصال والإشارة.

## الميزات المستهدفة

- واجهة عربية.
- عرض معلومات الإشارة: RSRP وRSRQ وSINR وPCI.
- اختبار الاتصال بصفحة الراوتر.
- إضافة شعار HATIM 5G.

## البناء

يستخدم المشروع Python وKivy وBuildozer لبناء APK عبر GitHub Actions.

1. افتح تبويب Actions في المستودع.
2. اختر Build HATIM 5G APK.
3. اضغط Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل ملف HATIM5G-debug-apk.

## تنبيه

هذه نسخة تطوير أولية. قراءة قيم الإشارة الحقيقية وتسجيل الدخول إلى Huawei H155-383 تحتاج إلى تنفيذ واختبار مستقلين؛ لا تعني واجهة التطبيق وحدها أن هذه الوظائف أصبحت تعمل.
