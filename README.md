# HATIM 5G

تطبيق أندرويد لإدارة راوتر Huawei H155-383 وقراءة معلومات الاتصال والإشارة.

## الوظائف

- واجهة عربية بتبويبات منفصلة للرئيسية و4G LTE و5G NR ومعلومات الخلية والإعدادات.
- قراءة بيانات الإشارة والخلية من واجهات Huawei HiLink القياسية، مع عرض الحقول التي يرسلها الراوتر فقط.
- الاحتفاظ بملفات Cookies ورموز الحماية خلال جلسة HTTP، ومحاولة تسجيل الدخول عند إدخال كلمة المرور.
- عنوان افتراضي قابل للتعديل: `http://192.168.9.1`، وتحديث يدوي أو تلقائي.
- تضمين خط Noto Naskh Arabic المرخص داخل APK بواسطة سير عمل البناء.

## البناء

يستخدم المشروع Python وKivy وBuildozer لبناء APK عبر GitHub Actions.

1. افتح تبويب Actions في المستودع.
2. اختر Build HATIM 5G APK.
3. اضغط Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل ملف HATIM5G-debug-apk.

يثبت `buildozer.spec` إصدار python-for-android على `v2024.01.21` لتجنب ترقية Python الهدف تلقائيًا إلى إصدار غير مدعوم من Kivy 2.3.0. يشغّل سير العمل اختبارات المحللات وبروتوكول HTTP المحاكى، ويتحقق من وجود الخط داخل APK.

## حدود التحقق

اختبارات المحللات تستخدم fixture بشكل استجابة Huawei، واختبارات الاتصال تستخدم خادم HTTP محليًا لمحاكاة Cookies وCSRF وتسجيل الدخول؛ العينة ليست capture من راوتر H155-383. لم يُختبر التطبيق على الراوتر الفعلي، لذلك لا نؤكد توافق واجهاته أو نجاح الاتصال به حتى يُختبر الجهاز. واجهة Huawei القياسية قد تعرض الخلية الحالية فقط، ولا تُعرض أبراج مجاورة ما لم يرسلها الراوتر.
